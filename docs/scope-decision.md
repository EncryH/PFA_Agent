## 1. 방어 계층 최종안

```
0. 악성 앱 탐지        기기에 원격제어·사칭 앱이 있는가
                       (은행 기존 자산 — 화면 표시만, 구현 안 함)
───────────────────────────────────────────────
1. 상대방 검증          번호·링크가 진짜 기관인가          [화이트리스트]
2. 행동 감지            앱에서 평소와 다른 행동을 하는가    [시퀀스 룰]
3. 거래 검사            이 거래가 평소와 다른가            [패턴 룰]
4. AI 의도 분석         이 돈을 왜 보내는가                [LLM + 룰]
   └ 통화 중 확인 → 5분 냉각
5. 가족 확인·권한 위임  혼자 결정하지 않게                 [상태 머신]
   └ 요청자 역검증 (딥보이스 대응)
6. 골든타임 사후 대응   뚫려도 되돌린다                    [절차 안내]
───────────────────────────────────────────────
금융보안원 허브: 은행이 달라도 가족이 연결됩니다 (라벨 + 은행 로고 2개)
```

## 2. 할 것 / 안 할 것

### 🔴 MUST — 이게 없으면 서비스가 아님

| # | 항목 | 비고 |
|---|---|---|
| 1 | 3층 거래 검사 (패턴 룰) | 0점이면 즉시 송금 = 무마찰 보장 |
| 2 | 4층 AI 의도 분석 | **실제 LLM 호출 필수.** mock이면 심사에서 무너짐 |
| 3 | 5층 가족 확인 + 권한 레벨 | 상태 머신, 실시간 알림 |

| 항목 | 이유 |
|---|---|
| 악성 앱 실제 탐지 | 웹에서 불가 (네이티브 권한) |
| 실시간 통화 분석 | SKT 에이닷이 이미 함 (통신사 영역) |

| 화이트리스트 앱·계좌 | 번호·링크만으로 데모 충분 |
| 다자녀·음성 안내·운영자 화면 | 범위 밖 |
| 실계좌·실송금·실제 신고DB API | 전부 가상 처리 |

## 3. 26일 일정

| 주차 | 기간 | 목표 | 완료 기준 |
|---|---|---|---|
| **W1** | 8/12~8/18 | **3→4→5층 E2E 관통** | 정상 송금 통과 + 위험 송금 → 대화 → 보류 → 자녀 알림 → 응답이 한 번에 돌아감 |
| **W2** | 8/19~8/25 | 1층·2층·6층 + 부가 질문 | 시나리오 4개 시연 가능 |
| **W3** | 8/26~9/1 | **기획서 + 기능명세서 + 평가셋** | 문서 초안 완성 |
| **W4** | 9/2~9/7 | 배포 안정화 + 리허설 + 동결 | **새 기능 금지** |

### ⚠️ 방어선

> **W1이 끝났는데 E2E가 안 돌면, 그 시점부터 SHOULD 항목을 전부 버린다.**

이 선을 지금 정해두지 않으면 마지막 주에 반쯤 만든 기능 다섯 개를 붙들게 됩니다.

## 4. 구현 / 가상 경계

기능명세서 "한계" 항목에 명시할 내용.

| 진짜로 구현 | 가상 처리 |
|---|---|
| AI 의도 대화 (실제 LLM) | 신고 DB (더치트·경찰청) |
| 위험 채점 룰 엔진 | 계좌·잔액·거래내역 |
| 가족 알림 실시간 전달 | 실제 송금 실행 |
| 보류·해제 상태 전이 | 악성 앱 탐지 |
| 감사 로그 | 크로스뱅크 연동 |

왼쪽이 mock이면 심사에서 무너집니다. 오른쪽은 제휴·네이티브 권한이 필요해 애초에 불가능하므로 명시만 하면 됩니다.
