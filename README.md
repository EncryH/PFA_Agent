# 안심동행 AI

> **2026 금융 AI Challenge**

고령 부모의 위험 송금을 AI가 금융 데이터와 대화 분석으로 탐지하고, 가족이 함께 확인하며, 피해 발생 시 골든타임 대응부터 회복까지 함께하는 가족 금융안전 서비스.

한결은행(부모)·나눔은행(자녀) — 서로 다른 가상 은행 앱 안의 기능으로 구현.
가족이 같은 은행을 쓰지 않아도 연결된다는 점을 데모에서 그대로 보여준다.

---

## 왜 필요한가

대한민국은 2024년 말 초고령사회에 진입했습니다. 보이스피싱 피해는 2022~2023년 감소세를 보이다 **2024년 8,545억원으로 역대 최고치**를 기록, 2025년에는 8월까지만 8,856억원으로 이미 전년을 넘어섰습니다.

**보이스피싱 피해 금액 추이** (억원, 경찰청)

![보이스피싱 피해 금액 추이](assets/voice-phishing-damage.svg)

**60대 이상 피해 비율 추이** (%)

![60대 이상 보이스피싱 피해 비율 추이](assets/elderly-victim-ratio.svg)

- 60대 이상 피해 비율 **30.6%** (2025 상반기) — 전 연령 중 1위, 10년간 피해 건수 **5배** 증가
- 2025년 1분기 기관사칭형 비율 **51%**로 급증 (전년 41% → +10%p)
- 기존 대응은 **방임**(사고 후 발견) vs **성년후견**(자기결정권 박탈)의 양극단

**안심동행 AI**는 이 사이에 존재하지 않던 **중간 단계**를 만듭니다. 감시가 아닌 동행으로, 부모님의 자기결정권을 지키면서 가족이 함께 보호합니다.

> 출처: 경찰청 보이스피싱 현황, 금융감독원 보도자료, 통계개발원 (2025)

## 아키텍처

```txt
┌──────────────────────────────┐
│ User 송금 시도                │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 1. 상대방 검증                │
│ - 수취 계좌 확인              │
│ - 전화번호·연락채널 검증       │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 2. 행동 감지                  │
│ - 한도상향 직후 송금           │
│ - 반복 입력·긴 세션 감지       │
└──────────────┬───────────────┘
               ↓
┌──────────────────────────────┐
│ 3. 사기 송금 의도 분석         │
│ - 고액·신규 수취인 빠른 신호    │
│ - 이전 거래 패턴 조회          │
│ - 개인정보 전처리             │
│ - RAG 사기 근거 검색          │
│ - LLM 위험 의도 판단          │
│ - JSON 결과 구조화            │
└───────┬──────────────────────┘
        │
        ├── 위험 낮음
        │       ↓
        │   정상 송금 진행
        │
        └── 고위험
                ↓
┌──────────────────────────────┐
│ 4. 피해 대응 (골든타임)       │
│ - 지급정지 요청               │
│ - 112 신고                   │
│ - 피해구제 신청               │
│ - 증거 보관                  │
└──────────────────────────────┘

선택 기능: 가족 보호
- 자녀에게 최소 위험 정보 공유
- 승인·보류 의견과 보호 단계 설정
- 최종 결정권은 부모가 유지
```

코드에서도 순차 파이프라인과 선택 기능을 분리한다.

```txt
backend/agents/
├─ 1-counterparty-verification/
├─ 2-behavior-detection/
├─ 3-intent-analysis/
└─ 4-damage-response/

backend/features/
└─ family-protection/

shared/
└─ family-protection-policy.json  # 프론트·백엔드 가족 보호 정책 정본
```

가족 보호 Lv.0~3의 이름·설명·권한·지연시간은 `shared/family-protection-policy.json` 한 곳에서 관리하며, 프론트 화면과 백엔드 판단이 같은 정책을 사용한다.

## 사기 송금 의도 분석

3단계는 현재 거래의 빠른 위험 신호를 먼저 확인하고, 의심 송금 상황과 송금 이유를 받으면 민감정보를 전처리한 뒤 RAG 검색과 Text2SQL 조회를 병렬로 수행한다. 이후 금융사기 근거와 개인 거래 패턴을 결합해 LLM이 사기 송금 의도를 분석하고, 위험도와 다음 보호 조치를 JSON 형태로 구조화한다. 앱 설치·원격제어 요구는 독립 단계가 아니라 이 의도분석의 위험 신호로 다룬다.
