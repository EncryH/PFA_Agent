# 2026 금융 AI Challenge HWPX 작성 가이드

## 기본 원칙

- 공식 양식의 제목, 팀 정보, 번호, 필수항목 순서를 유지한다.
- 공식 표 구조는 삭제하거나 새로 만들지 않고, 각 내용 칸의 높이만 내용에 맞게 늘린다.
- 안내 문구인 `<- ... >`는 실제 내용을 입력한 뒤 모두 삭제한다.
- 본문은 검정 또는 짙은 회색, 핵심어만 굵게 표시한다.
- 강조색은 네이비와 블루만 사용하고 위험 화면에서만 빨강을 사용한다.

## 내용 서식

- 항목 제목: 양식에 적용된 네이비 굵은 글씨 유지
- 본문: 10~10.5pt, 줄간격 150~160%, 왼쪽 정렬
- 소제목: 11~12pt, 굵게, 네이비
- 표 머리글: 연한 블루 배경, 네이비 글씨
- 그림: 페이지 폭 안에서 가운데 정렬
- 그림 캡션: `그림 4-A. 3단계 AI 송금 의도 분석 결과 화면`
- 표 캡션: 필요한 경우에만 표 위에 작성

## 이미지 배치

- 한 페이지에 큰 이미지 1개 또는 세로형 앱 화면 2개까지만 배치한다.
- 모든 앱 이미지는 같은 높이와 여백으로 맞춘다.
- 기술 화면은 전체 화면보다 핵심 결과가 읽히는 크기로 자른다.
- 같은 이미지를 기획서와 기능명세서에 반복해서 넣지 않는다.

## 제출 전 확인

1. 팀명과 구성원 성명을 확인한다.
2. 모든 필수항목이 작성됐는지 확인한다.
3. 안내 문구와 빈 표가 남지 않았는지 확인한다.
4. 이미지, 표, 문장이 페이지 밖으로 잘리지 않았는지 확인한다.
5. HWPX 원본은 보관하고 최종 제출본은 PDF로 변환한다.
6. 변환된 PDF의 글꼴, 링크, 페이지 순서와 빈 페이지를 확인한다.
